# Chinese Antiques — Scientific Library of Research and Attribution

English-language scientific portal by Professor Nona Dronova on Chinese porcelain, jade and bronze:
monographs (English translation), the Diagnostic Atlas of Chinese Porcelain, literature and Zenodo publications.

## Editing

All pages are generated by `tools/build.py` (Python 3.12+, pandoc).

- Chapter texts: `tools/content/porcelain/chNN.md` (Markdown). A chapter appears on the site as soon as its file exists.
- Styles: `assets/style.css`
- Images: `images/`

Rebuild after any change:

```
python3 tools/build.py
```

Hosted on Vercel (static, no build step).

## Quality check

Serve the site locally (`python3 -m http.server 8765`) and run `python3 tools/audit.py`.
It checks every page at 1366, 768 and 390 px: broken links and anchors, missing images,
horizontal overflow, cropped photographs, button alignment, Back to Home, titles,
descriptions, H1 and structured data.
